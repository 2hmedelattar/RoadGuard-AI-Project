# Python Modules and Packages

## 1. What We Learned

- A Module is a Python file containing reusable code.
- A Package organizes related Python modules.
- `__init__.py` marks a regular Python package and can initialize package-level behavior.
- `import` allows modules to reuse code from other modules.
- Modules and packages help organize an application into maintainable components.

## 2. Modules

A Python module is a `.py` file containing Python code.

Modules can contain:

- Variables.
- Functions.
- Classes.
- Imports.
